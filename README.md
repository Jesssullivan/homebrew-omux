# homebrew-omux

Public Homebrew tap for `oauth-mux`.

Install:

```bash
brew tap jesssullivan/omux https://github.com/Jesssullivan/homebrew-omux.git
brew install jesssullivan/omux/oauth-mux
```

Formula updates are derived from public `Jesssullivan/oauth-mux` GitHub
Release assets, especially `oauth-mux.rb` and `SHA256SUMS`. Do not publish
workstation-built formulas here.

Rollback is a normal tap revert: revert the formula commit, run `brew update`,
and rerun install QA against the last known good `oauth-mux` release.
